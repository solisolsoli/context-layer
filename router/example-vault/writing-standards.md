# Writing standards

The current, binding house style for every published note. If an older document
disagrees with this file, this file wins.

## Summary line

Every note opens with one summary line of **40 to 80 visible characters**,
punctuation and spaces included. One line, no forced line break, no arrow, no
trailing "read on".

## Body

The body is a single paragraph of 120 to 160 words. It states what changed, who
decided it, and what the reader has to do next. It does not restate the summary
line.

## Sourcing

Any factual claim names the file it came from. A claim with no named source is
marked as an open question instead of being written as a fact. A draft is not a
decision, and silence is not approval.

## Terminology

Use the terms defined in `reference-docs/glossary.md`. Do not invent a synonym
for a term that already has a definition there.
