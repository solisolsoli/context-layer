# Glossary

Canonical definitions. A term used in a note means what it means here.

- **summary line** — the single opening line of a note, 40 to 80 visible characters.
- **packet** — a bundle of verbatim source passages assembled for one prompt.
- **route** — a named group of trigger terms and the canonical files they open.
- **canonical source** — a file a route always opens, regardless of search rank.
- **open question** — a claim with no named source; never written as a fact.
