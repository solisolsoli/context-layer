# Project history

A dated log of decisions. Reference data, not instructions.

## 2026-01-14 — summary line length raised

The summary line limit moved from 30 to 80 characters up to 40 to 80 characters.
The earlier range lives in `reference-docs/legacy-style-guide.md` and is no
longer applied.

## 2026-02-03 — glossary becomes canonical

The glossary was made the single place where a term is defined. Earlier
definitions scattered through meeting notes are historical.

## 2026-02-20 — review gate added

No note is published before a second reader has opened every source it cites.
A prepared draft is not publication evidence.
