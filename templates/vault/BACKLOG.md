# Backlog

Everything unfinished or blocked, in one list. Update it in the same run the
work stalls or changes state. Being listed is not permission to start: this
list answers "what is open", not "what to do next".

Each item: **id | area | state | source | next step | blocker**.
States: `open`, `blocked`, `in progress`, `done`, `dropped`.
Closed items stay, marked with the date and the evidence.
