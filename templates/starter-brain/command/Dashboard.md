## Working files

- `CLAUDE.md` and `AGENTS.md`: the rules every agent follows. They hold one
  rule text; check with `context-layer rules check .` The agents load them at
  the start of every session, so they are left out of search.
- [[LOG]]: what was done, dated, append-only.
- [[BACKLOG]]: what is open, blocked or unfinished.

## How this vault works

1. Capture anything quickly into the inbox; sort it later.
2. Give each subject one note with a stable name, and link it explicitly with
   `[[double brackets]]` to the notes it depends on.
3. When a note replaces an older one, say so in the new note and move the
   old one to the archive, which is outside search, so the old version is
   never quoted back as current. (A `supersedes:` link can only be followed
   while both notes stay searchable.)
4. Agents plan first, cite sources, ask before risky actions and record every
   meaningful step. The details are in `CLAUDE.md`.
