# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone taking part in the project's
spaces: issues, pull requests, discussions and reviews.

In short: be respectful, assume good faith, criticise work rather than people,
and do not harass anyone.

## Reporting

- Conduct that needs private handling: use GitHub's private reporting on this
  repository (**Security** tab → **Report a vulnerability**) and say in the
  title that it is a conduct report, not a security issue. Only the maintainers
  can read it.
- Anything that can be public: open an issue addressed to the maintainers.

The project is run by a small number of maintainers, who will review reports,
decide on a response in line with the Covenant's enforcement guidelines, and
keep the reporter's identity private. There is no separate appeals body.
