# Orchard Docs — writing style guide

Status: canonical. Last reviewed 2026-08-30.

## Summaries

Every page opens with a one-line summary. The summary is **80 to 100 characters**
of visible text, counted including spaces and punctuation. Shorter summaries are
rejected by the docs linter; longer ones are truncated in search results.

## Voice

Write in the second person. Do not use the phrase "simply" or "just" in
instructions — reviewers have rejected pages for it twice.

## Screenshots

A screenshot never replaces the text it illustrates. If the screenshot is
removed the page must still be complete.
