# API versioning policy

Status: canonical. Last reviewed 2026-09-10.

The current scheme is **CalVer** (`YYYY.MM.PATCH`). Adopted 2026-07-01.

Historical note: the vault used **SemVer** (`MAJOR.MINOR.PATCH`) until
2026-06-30. SemVer references in older pages are superseded by this document.

Breaking changes require a deprecation window of 90 days.
