# Incident runbook

Status: canonical. Last reviewed 2026-09-05.

Page the on-call engineer first, then open the incident doc. Do not start a
public status post before the on-call has confirmed impact.

Known pitfall: during the 2026-05 outage, two responders edited the same
incident doc at once and one set of notes was silently overwritten. Claim the
doc in the channel before editing it.
